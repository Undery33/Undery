## 이 글은 예제입니다

기술 글 목록, 태그 필터, 검색과 상세 페이지를 확인하기 위한 예제 콘텐츠입니다.
실제 개인 이력이나 활동을 나타내지 않습니다.

## 글 작성 방법

`content/computer` 디렉터리에 Markdown 파일을 추가합니다.
파일명은 `my-first-post.md`처럼 영문 소문자와 숫자, 하이픈으로 작성합니다.

- 제목과 요약은 글 목록에 표시됩니다.
- 태그를 누르면 같은 주제의 글을 모아 볼 수 있습니다.
- 검색은 제목, 요약, 태그와 본문을 대상으로 합니다.

```ts
const message = "기록은 다시 꺼내 볼 때 더 유용해집니다.";
console.log(message);
```

> 공개 저장소에 올리는 글과 초안에는 비밀번호나 개인정보를 넣지 않습니다.

## 지원하는 표현

**강조**, *기울임*, 목록, 링크와 코드 블록을 사용할 수 있습니다.
원시 HTML과 실행 가능한 MDX는 지원하지 않습니다.
