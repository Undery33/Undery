## 변경은 작게, 목적은 분명하게

이 글은 검색과 태그 기능을 확인하기 위한 두 번째 예제입니다.
실제 서버의 배포 절차가 아닙니다.

작업 브랜치는 `feature/article-search`처럼 기능을 알아볼 수 있는 이름을 사용합니다.
작업을 마치면 변경 범위를 확인하고 검사를 실행합니다.

```sh
npm run check
npm run build
```

## 리뷰 전에 확인할 것

1. 새 기능과 기존 경로가 의도대로 동작하는지 확인합니다.
2. 빈 결과와 잘못된 주소도 확인합니다.
3. 비밀값이나 개인 데이터가 포함되지 않았는지 살펴봅니다.
4. 아직 구현하지 않은 기능은 문서에 분명히 남깁니다.

배포는 별도 승인과 서버 설정 검토 후 진행합니다.
